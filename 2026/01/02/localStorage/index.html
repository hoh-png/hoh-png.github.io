localStorage

localStorage 是浏览器提供的本地存储 API，用于持久化存储字符串数据（关闭浏览器、重启电脑后数据仍存在），存储大小约 5MB，仅在客户端生效，不涉及后端交互。

下面分「纯 HTML/JS 场景」和「JSX（React/Vue3）场景」详细讲解，覆盖日常开发中 90% 以上的用法和思路。

一、先掌握 localStorage 核心基础（跨场景通用）

无论哪种场景，先吃透这 5 个核心方法，所有用法都是基于这些基础扩展的：

1. 存储数据：localStorage.setItem(key, value)

  • 说明：key（键名）和value（值）都必须是字符串类型（如果不是字符串，浏览器会自动转换为字符串存储）。

3. 删除单个数据：localStorage.removeItem(key)

5. 获取存储的键名：localStorage.key(index)

重要注意点（新手必踩坑）

  1. localStorage 仅支持字符串数据，无法直接存储对象、数组、日期等复杂类型。
  2. 数据是按域名隔离的，http://localhost:8080 和 http://localhost:3000 是两个不同域名，数据不互通。
  3. 没有过期时间，除非手动删除或清空浏览器缓存，否则数据永久存在。

二、纯 HTML/JS 场景（分离文件 / 单文件）

这是最基础的场景，适合静态页面、原生 JS 项目，主要分为「HTML 和 JS 分离文件」和「HTML 内嵌 JS 单文件」两种写法，核心思路一致，只是文件组织形式不同。

核心思路（纯 HTML/JS）

  1. 先判断浏览器是否支持 localStorage（兼容低版本浏览器 / 非浏览器环境）。
  2. 存储复杂数据（对象、数组）时，先通过JSON.stringify()转为 JSON 字符串。
  3. 获取复杂数据时，先通过JSON.parse()解析为原数据类型（对象、数组）。
  4. 避免直接操作原始数据，先做数据校验（防止null解析报错）。

三、JSX（React/Vue3）场景（组件化开发）

JSX 场景主要用于 React（React Native 不支持 localStorage，需注意）、Vue3（JSX 语法），核心思路和纯 HTML/JS 一致，但结合了组件化、状态管理、生命周期 / 钩子函数，这是和纯 HTML/JS 的核心区别。

核心思路（JSX）

  1. 兼容性判断仍需保留（可选，现代浏览器基本都支持）。
  2. 复杂数据仍需通过JSON.stringify()/JSON.parse()转换。
  3. 结合组件钩子函数（React：useEffect；Vue3：onMounted/onUpdated）实现「页面加载获取数据」「状态更新同步存储数据」。
  4. 组件状态（useState/ref）和 localStorage 数据保持同步，实现「响应式更新」。

四、总结（新手重点回顾）

  1. 核心基础：5 个方法（setItem/getItem/removeItem/clear/key），仅支持字符串存储，复杂数据需用JSON.stringify()/JSON.parse()转换。
  2. 纯 HTML/JS 场景：重点是文件组织（分离 / 单文件）和数据渲染，适合静态页面和原生 JS 项目。
  3. JSX 场景：重点是「组件状态与 localStorage 同步」，结合钩子函数（useEffect/onMounted）和工具类封装，适合 React/Vue 组件化项目。
  4. 开发避坑：兼容性判断、null解析校验、按域名隔离、无过期时间（需手动封装）。
  5. 高频用法：复杂数据存储、数据更新同步、工具类封装、带过期时间的存储，这些是日常开发中使用频率最高的场景，务必熟练掌握。
