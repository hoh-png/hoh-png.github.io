Fetch_API网络请求

Fetch API - 就像点外卖 🍔

简单比喻

Fetch API 就是 JavaScript 用来从网上拿数据的工具，就像你用手机 APP 点外卖：

  1. 你 = 你的 JavaScript 代码
  2. 外卖APP = Fetch API
  3. 餐厅 = 服务器/网站
  4. 外卖 = 数据（JSON、图片、文本等）

最基本的外卖订单（GET 请求）

场景：从网上获取用户信息

分步解释：

  1. fetch('网址') - 打电话给餐厅下单
  2. .then(response => response.json()) - 外卖送到了，拆开包装袋
  3. .then(data => ...) - 拿出汉堡开始吃
  4. .catch(error => ...) - 处理送餐出错

实际例子：获取天气预报

不同种类的“外卖订单”（请求类型）

1. GET - 查看菜单（获取数据）

2. POST - 下单点菜（发送数据）

3. PUT - 修改订单（更新数据）

4. DELETE - 取消订单（删除数据）

处理不同类型的“外卖”（响应数据）

1. JSON 数据（最常见）

2. 文本数据

3. 图片数据

错误处理大全

情况1：网络错误（断网了）

情况2：服务器错误（餐厅关门了）

情况3：超时处理（外卖太慢了）

实际项目完整示例

Fetch vs 传统 AJAX

特点 Fetch API 传统 AJAX (XMLHttpRequest)
写法 Promise-based，更简洁 回调函数，较繁琐
默认 不发送cookies 发送cookies
错误处理 只在网络错误时reject 需要手动检查状态码
兼容性 现代浏览器支持 所有浏览器支持
推荐度 ⭐⭐⭐⭐⭐（推荐） ⭐⭐（老项目用）

记住这个万能模板

核心要点：

  1. fetch() 是起点
  2. .then() 或 await 处理响应
  3. response.json() 解析数据
  4. try/catch 处理错误
  5. 检查 response.ok 确认成功

就像点外卖：下单 → 等待 → 拆包装 → 享用！ 🚚➡️📦➡️🍔
