this

先说this
this 是一个特殊的关键字，它在函数被调用时自动创建，指向调用该函数的对象。

核心理解：this 的值不取决于函数在哪里定义，而取决于函数被谁调用，以及如何被调用。

this 的几种绑定规则

规则1：默认绑定（独立函数调用）

当函数独立调用（不是作为对象的方法）时，this 指向全局对象。

规则2：隐式绑定（方法调用）

当函数作为对象的方法被调用时，this 指向调用该方法的对象。

规则3：显式绑定（使用 call, apply, bind）

我们可以强制指定 this 的值。

call 和 apply - 立即调用

bind - 创建新函数，不立即调用

规则4：new 绑定（构造函数）

当使用 new 关键字调用函数时，this 指向新创建的对象。

规则5：箭头函数的 this

箭头函数没有自己的 this，它会继承外层作用域的 this。

常见的 this 陷阱

陷阱1：回调函数丢失 this

陷阱2：方法赋值给变量

this 的优先级总结

从高到低：

  1. new 绑定 (new Foo())
  2. 显式绑定 (call, apply, bind)
  3. 隐式绑定 (obj.method())
  4. 默认绑定 (独立函数调用)

实践建议

  1. 在对象方法中：使用普通函数，this 指向调用对象
  2. 在回调函数中：使用箭头函数，继承外层 this
  3. 需要明确指定 this 时：使用 call, apply, bind
  4. 构造函数中：使用 new 关键字
