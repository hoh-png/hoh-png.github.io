class

class 是 JavaScript 中实现面向对象编程（OOP）的核心语法。
简单说：class 是一个蓝图或模板，用于创建具有相同属性和方法的多个对象。

生活比喻：

想象你要造汽车：

· class Car 就是汽车的设计图纸
· new Car() 就是根据图纸生产出一辆真正的汽车
· 每辆真正的汽车都是独立的，但它们都有图纸规定的相同结构（有轮子、能加油、能驾驶）
class 的基本结构

class 的详细组成部分

  1. 构造函数 constructor

· 每个类只能有一个 constructor
· 在 new 创建对象时自动调用
· 用于初始化对象的属性

  1. 实例方法

· 定义在类中的函数
· 所有对象共享相同的方法（但 this 指向各自的对象）
· 通过对象来调用：对象.方法名()

  1. 静态方法 static

· 属于类本身，不属于任何对象
· 通过类名调用：类名.方法名()
· 不能访问实例属性（因为不通过对象调用）

  1. 继承 extends

子类可以继承父类的属性和方法。

  1. Getter 和 Setter

用于控制对属性的访问。

  1. 私有字段 #

ES2022 新增，真正私有的属性，外部无法访问。

class 的本质

重要理解：JavaScript 的 class 本质上是语法糖，它底层还是基于原型的继承。

但 class 语法更清晰、更安全、更接近传统面向对象语言。

总结

· class：创建对象的蓝图/模板
· constructor：创建对象时自动调用，初始化属性
· 实例方法：对象的行为，通过对象调用
· 静态方法：属于类本身，通过类名调用
· 继承：extends 创建子类，super 调用父类
· Getter/Setter：控制属性访问
· 私有字段：# 开头的属性，真正私有

使用建议：

· 当需要创建多个相似对象时使用 class
· 相关的数据和操作封装在一起
· 使用继承来复用代码
· 现代 JavaScript 开发中，class 是组织代码的主流方式
